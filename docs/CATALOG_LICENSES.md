## Notas importantes

1. **Os 6 craft apps "puros" (photocraft, vectorcraft, lightcraft, wordcraft, designcraft, artcraft) são open source de verdade** (dupla MIT/Apache-2.0). O GitHub mostra "Apache-2.0" no campo de licença, mas o README e a raiz do repo trazem `LICENSE-MIT` + `LICENSE-APACHE` — ou seja, quem usa escolhe uma das duas.

2. **artcraft-services é a exceção crítica**: apesar de público, usa a "ArtCraft License (WIP)", declaradamente "fair source", e proíbe explicitamente vender o software ou construir produto concorrente com o código. Como o Tools Hub é uma plataforma de ferramentas, **nenhum código desse repo deve ser adaptado** sem permissão escrita dos autores. Por isso ele **não** entrou no catálogo.

3. **artcraftx não tem licença verificável**: sem arquivo de licença e sem declaração no GitHub. Sem licença = todos os direitos reservados. **Nenhum código deve ser adaptado.** Também ficou fora do catálogo.

4. **Licença do código ≠ custo de uso**: ArtCraft (app) é MIT/Apache-2.0, mas a geração de imagem/vídeo dentro dele usa provedores pagos (Kling, Sora, Midjourney etc.) — contas e custos são separados e exigem aprovação.

5. Re-verificar licenças antes de qualquer adaptação real de código (licenças podem mudar; o fair-source do artcraft-services está marcado como "WIP").
